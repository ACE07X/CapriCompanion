## mochiiwuff/capri-desktop — reference only

Repository: <https://github.com/mochiiwuff/capri-desktop>

Its `LICENSE` is MIT for that repository's source code and identifies the copyright holder as “2026 Capri Desktop contributors.” The project's README explicitly says its character artwork in `assets/capri/` and `docs/` is not covered by MIT and belongs to its respective rights holders.

This project uses the repository as a design reference for pose-to-pose animation, cursor-aware reactions, visual action beats, and desktop-roaming behaviours (perching on windows, peeking from screen edges, teleporting, falling when dropped). CapriCompanion's roaming window (`web/pet.js`) is original code driving the separately licensed Lachy sprites; mochiiwuff's WebGL rig is built around its excluded artwork and was not used. No source code or artwork from `mochiiwuff/capri-desktop` is redistributed here, so its MIT license does not apply to CapriCompanion files. If code from that repository is added later, preserve its MIT notice in a separate third-party license record and identify the affected files. Its excluded anime-derived artwork must not be treated as MIT-licensed.
